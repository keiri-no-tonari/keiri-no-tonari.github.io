プライバシーポリシー

経理のとなり（代表 佐藤 尚斗。以下「当方」）は、「経理のとなり」の提供にあたり、お客様の個人情報を次のとおり取り扱います。

1. 取得する情報

お名前、会社名・屋号、メールアドレス、電話番号、業種などのお申し込み情報。ご依頼いただいた領収書・請求書などの証憑と、そこに書かれた取引先や金額などの情報。

2. 利用目的

  • ご相談への回答、先行導入のご案内
  • 記帳・月次レポートなど、ご契約いただいたサービスの提供
  • ご本人確認、料金のご請求、お問い合わせへの対応
  • サービスの改善（個人を特定できない形に加工したうえで行います）

3. 業務の委託

サービスの提供のため、次の事業者に情報の取り扱いを委託します。委託先は必要な範囲で選び、適切に管理します。

  • 処理を行うサーバー：さくらインターネット株式会社（日本）
  • 証憑の受け取りと、暗号化した控えの保管：Google LLC（アメリカ合衆国。Google ドライブ）
  • 会計帳簿と証憑の保存：freee株式会社（日本）
  • 作業の管理と承認の記録：Notion Labs, Inc.（アメリカ合衆国）
  • 料金の決済：Stripe（カード番号は Stripe が直接お預かりし、当方は保存しません）

いまは、証憑の中身を外部の AI サービスには送っていません。使い始めるときは、委託先と送る範囲を事前にお知らせし、同意をいただいてからにします。

外国にある事業者への委託については、その国の個人情報保護の制度と、委託先が講じている措置を、お問い合わせに応じてお知らせします。

4. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく第三者に提供しません。税理士などをご紹介するときも、事前にご同意をいただきます。

5. 安全管理

  • 担当者を限ってアクセスを管理します。処理を行うサーバーは、インターネットから直接には入れないようにしています
  • 仕訳は担当者が確認し、お客様が承認してから登録します
  • 控えは暗号化して保管し、鍵は控えとは別の場所で管理します
  • 証憑の原本は削除しません

6. Google のデータの取り扱い

当方のシステムは、当方が管理する Google ドライブのフォルダにだけアクセスし、証憑の受け取り、月次レポートのお渡し、暗号化した控えの保管に使います。Google API から得た情報は、この目的のほかには使わず、広告に使ったり第三者に売ったりしません。Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含みます）に従います。
